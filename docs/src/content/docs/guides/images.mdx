This guide renders still images of a map and reads their pixels, without a
window. It starts with a runtime from
[Create a map](/maplibre-native-ffi/guides/create-a-map/).

## Create the map

Create a map in static mode, at the image size you want in logical pixels. For a
higher-resolution image, raise the scale factor: a scale factor of 2 doubles the
image's width and height in pixels.

<Snippet page="images" region="map" />

## Load a style

Set the style URL. You don't need to wait for the style to load, because the
image request waits for it. To load style JSON, see
[Style](/maplibre-native-ffi/guides/style/).

<Snippet page="images" region="style" />

## Attach a texture

Have the library create a GPU device, then attach a texture on that device to
the map, at the map's size. Wait for the attach to finish, and use the render
session it returns. Close the device after you close the session.

<Snippet page="images" region="attach" />

## Render an image

Jump the camera to the view you want. See
[Move the camera](/maplibre-native-ffi/guides/camera/#move-the-camera).

To change the image size, resize the render session, and it resizes the map too.

Request a still image, and wait for it. You don't need to wait for the camera or
the resize first.

A map renders one image at a time. Request the next image after this one
finishes.

<Snippet page="images" region="image" />

## Read the pixels

Read the session's texture after the image finishes. The result has RGBA pixels
row by row, and the stride is the number of bytes in each row.

To use the images on the GPU instead, see
[Render to a texture](/maplibre-native-ffi/guides/texture/).

<Snippet page="images" region="read" />

## Render map tiles

For map tiles, such as on a tile server, create the map in tile mode instead.
Make it square, at the tile size that your map clients expect, such as 256
or 512. For `@2x` tiles, set the scale factor to 2 and keep the size.

To render tile z/x/y, jump to the tile's center. A tile at zoom z is 512 logical
pixels wide, so a 512-pixel map uses zoom z, and a 256-pixel map uses zoom z
− 1.
