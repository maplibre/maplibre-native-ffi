This guide introduces how to render still images of a map. Start with a runtime
from [Create a map](/maplibre-native-ffi/guides/create-a-map/).

## Create a static map

Create a map with [](api:MLN_MAP_MODE_STATIC), at the image size you want in
logical pixels. For a higher-resolution image, raise the scale factor: a scale
factor of 2 doubles the image's width and height in pixels. Then set its style,
as in [Create a map](/maplibre-native-ffi/guides/create-a-map/#set-a-style).

<Snippet page="images" region="map" />

## Attach a texture

Maps render on your GPU, so you need a graphics context to render a map. If your
app doesn't have a GPU context, the library can create one for you with
[](api:mln_graphics_device). Attach a texture on that device to the map with
[](api:mln_map_attach_graphics_device_texture), at the map's size. Use the
render session it returns. Close the device after you close the session.

<Snippet page="images" region="attach" />

## Render an image

A static map renders only when you request an image. Jump the camera to the view
you want, as in
[Move the camera](/maplibre-native-ffi/guides/camera/#move-the-camera), then
request a still image with [](api:mln_map_request_still_image).

To change the image size, resize the render session with
[](api:mln_render_session_resize), and it resizes the map too.

<Snippet page="images" region="image" />

## Read the pixels

Read the image's pixels with [](api:mln_render_session_read_texture).

To use the images on the GPU instead, see
[Render to a texture](/maplibre-native-ffi/guides/texture/).

<Snippet page="images" region="read" />

## Render map tiles

For map tiles, such as on a tile server, create the map with
[](api:MLN_MAP_MODE_TILE) instead. Make it square, at the tile size that your
map clients expect, such as 256 or 512. For `@2x` tiles, set the scale factor to
2 and keep the size.

To render tile z/x/y, jump to the tile's center. A tile at zoom z is 512 logical
pixels wide, so a 512-pixel map uses zoom z, and a 256-pixel map uses zoom z
− 1.
