The camera belongs to the map and can be configured before a render session
exists. Set the fields that you want to change; the other fields keep their
committed values.

<Code code={region(cameraSnippet, "camera")} lang="c" title="camera.c" />

## Choose a transition

A camera update selects jump, ease, or fly timing. Use jump for an initial or
restored position, or for a camera that the host computes each frame.

<Code code={region(cameraSnippet, "jump")} lang="c" title="camera.c" />

Use ease for a short move that remains easy to follow, with a duration to
animate it.

<Code code={region(cameraSnippet, "ease")} lang="c" title="camera.c" />

Use fly for a long move. Its curved path zooms out while crossing the distance.

<CameraPaths />

Keep requesting frames while the repaint flag is set, as
[Run the render loop](/maplibre-native-ffi/guides/run-the-render-loop/)
describes.

## Apply gesture input

Relative camera deltas apply pointer movement to the current camera. Prefer them
to computing a new camera from an earlier snapshot. Begin the gesture when the
interaction starts and end or cancel it when the interaction finishes.

<Code
  code={region(gestureSnippet, "bracket")}
  lang="c"
  title="camera-gesture.c"
/>

A drag uses the movement since the previous input in logical pixels.

<Code code={region(gestureSnippet, "drag")} lang="c" title="camera-gesture.c" />

A pinch combines centroid movement and scaling about the new centroid.

<Code
  code={region(gestureSnippet, "pinch")}
  lang="c"
  title="camera-gesture.c"
/>

A rotation or tilt can change bearing and pitch about the same anchor.

<Code
  code={region(gestureSnippet, "rotate")}
  lang="c"
  title="camera-gesture.c"
/>

Use an animated delta for release momentum, or end the gesture without changing
camera fields when it has no momentum.

<Code
  code={region(gestureSnippet, "release")}
  lang="c"
  title="camera-gesture.c"
/>

## Fit geographic bounds

Compute a camera that fits the region into the viewport. Pass padding in logical
pixels to leave room for overlays.

<Code
  code={region(fitBoundsSnippet, "padding")}
  lang="c"
  title="camera-fit-bounds.c"
/>

Apply the returned camera with the transition timing that you want.

<Code
  code={region(fitBoundsSnippet, "fit")}
  lang="c"
  title="camera-fit-bounds.c"
/>

## Observe or stop a transition

Set an end handler to learn when and how the transition ends.

<Code code={region(cameraSnippet, "end")} lang="c" title="camera.c" />

Cancel all transitions, or assign a transition ID to cancel a particular one.

<Code code={region(cameraSnippet, "cancel")} lang="c" title="camera.c" />

The [camera reference](/maplibre-native-ffi/reference/c/camera_8h.html) defines
animation options, gesture phases, and callback ordering.
