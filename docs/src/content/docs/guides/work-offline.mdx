Set a writable cache path in the runtime options to keep resources across host
runs. Without one, the cache lives in memory.

The ambient cache keeps recently fetched resources within a size budget. An
offline region keeps everything that a defined area needs, outside that budget.
Download a region when the host must draw a known area without a network.

Load MBTiles through an `mbtiles://` source instead.
