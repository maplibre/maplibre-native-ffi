Set a writable cache path in the runtime options to keep resources across host
runs. The default in-memory database lasts for the runtime's lifetime.

The ambient cache evicts fetched resources within a byte budget. Offline regions
retain the resources needed for defined areas outside that budget. Download a
region when the host must draw a known area without a network.

Database operations complete asynchronously. Copy borrowed results that the host
keeps before their completion callback returns.

## Import a downloaded database

Merge an offline database prepared by another runtime to import its regions.
Keep the file present and unchanged until the merge completes. Both databases
must use the same MapLibre offline schema. Load MBTiles through an `mbtiles://`
source instead.

The [map reference](/maplibre-native-ffi/reference/c/map_8h.html) defines region
operations, merge results, and storage controls.
