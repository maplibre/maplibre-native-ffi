## Receive callbacks on the host loop

A host that cannot run code on a native thread, such as a JavaScript engine,
creates one delivery queue and names it beside the callbacks of each
registration. Native code then queues each call instead of making it. The
queue's wake schedules a dispatch on the host loop, and each dispatch runs the
queued completions, event callbacks, and request callbacks there, in order. The
[delivery reference](/maplibre-native-ffi/reference/c/delivery_8h.html) states
the queue's rules.

## React to changes

A style-loaded event means that the style parsed and its sources exist. Add
host-owned sources and layers after this event, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

Keep a frame demand waiting for an update to render new map state.
[Run the render loop](/maplibre-native-ffi/guides/run-the-render-loop/) shows
how to request frames and drain their results.

A loading-failed event carries failure text for a style or resource request.
Observe command completions as well: events and completions report different
outcomes, as [Failures](/maplibre-native-ffi/concepts/#failures) explains.

Events carry generations for hosts that need to relate them to commands or
snapshots. The
[runtime reference](/maplibre-native-ffi/reference/c/runtime_8h.html) covers
payloads, queued-event ownership, and generation ordering.
