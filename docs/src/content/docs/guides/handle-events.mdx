## Receive callbacks on the host loop

A host whose runtime cannot run code on a native thread, such as a JavaScript
engine, receives every callback it need not answer at once through a delivery
queue: completions, log records, resource requests and their cancellations,
resource transform requests, camera transition ends, runtime event spans, and
custom source tile fetches and cancels. It creates one queue with a wake, and
sets that queue in place of the callbacks of each registration.

The wake schedules a drain on the host loop and returns promptly. A queue
that receives log records also follows the log callback restrictions: its wake
and wake release callback must not call the library. Each drain returns every
queued delivery in one owned batch, in push order. Take each handle that the
host keeps, such as a created map or a resource request, from the batch before
releasing it; the batch disposes what the host leaves. A drain that cannot
allocate its batch keeps the deliveries queued, and the next delivery wakes the
queue again; a host that cannot wait for it drains again on its own schedule.
The [delivery reference](/maplibre-native-ffi/reference/c/delivery_8h.html)
lists the delivery types and their payloads.

Use opaque host tokens as each registration's user data. Retain the token state
until its final delivery is handled, or abandon that state when releasing the
queue. A runtime release waits for native insertion of earlier deliveries; the
host may still have batches to drain afterward.

## React to changes

A style-loaded event means that the style parsed and its sources exist. Add
host-owned sources and layers after this event, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

Keep a frame demand waiting for an update to render new map state.
[Run the render loop](/maplibre-native-ffi/guides/run-the-render-loop/) shows how
to request frames and drain their results.

A loading-failed event carries failure text for a style or resource request.
Observe command completions as well: events and completions report different
outcomes, as [Failures](/maplibre-native-ffi/concepts/#failures) explains.

Events carry generations for hosts that need to relate them to commands or
snapshots. The [runtime reference](/maplibre-native-ffi/reference/c/runtime_8h.html)
covers payloads, queued-event ownership, and generation ordering.
