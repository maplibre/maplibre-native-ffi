A layer property contains a constant or an expression. An expression reads each
feature's data, allowing one rule to style every feature. A property value
belongs to the loaded style. Set it again after every later style load, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

Style properties use style-spec JSON values. A constant is a scalar, and an
expression is an array whose first element names the operator. The remaining
elements are its arguments. The C API accepts the complete UTF-8 JSON value as
one buffer view.

`["get", "mag"]` reads the feature property named `mag`, and `["linear"]`
names the interpolation curve. The snippet embeds both in the complete
expression.

The stop pairs scale a circle from 4 pixels at magnitude 1 to 24 pixels at
magnitude 6. A buffer view carries the expression without rebuilding its nodes at
the C boundary.

<Code code={region(styleByData, "property")} lang="c" title="style-by-data.c" />

Setting a property takes one layer and one property name, and the name is the
one that the style specification defines for that layer's type.

<Code code={region(styleByData, "set")} lang="c" title="style-by-data.c" />

A filter is a boolean expression that selects the source features to draw. It
uses the same value representation as a style property. An empty filter clears
the layer's filter. The snippet passes the complete filter expression.

<Code code={region(styleByData, "filter")} lang="c" title="style-by-data.c" />

The host owns the byte storage. MapLibre parses or copies a property value or
filter before the call returns.

Both commands apply to the live style in runtime submission order. A host that
drains render events and renders on update draws the new appearance in its next
frame.
