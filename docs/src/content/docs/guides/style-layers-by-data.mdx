A layer property holds a constant or an expression. An expression reads each
feature's data, so one rule styles every feature. A property value belongs to
the loaded style, so set it again after each later style load, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

Style properties use style-spec JSON. An expression is an array whose first
element names the operator, followed by its arguments.

`["get", "mag"]` reads the feature property named `mag`, and `["linear"]`
selects linear interpolation.
