A layer property contains a constant or an expression. An expression reads each
feature's data, allowing one rule to style every feature. A property value
belongs to the loaded style. Set it again after every later style load, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

Style properties use style-spec JSON values. An expression is an array whose
first element names the operator and whose remaining elements are its arguments.

<Code code={region(styleByData, "node")} lang="c" title="style-by-data.c" />

`["get", "mag"]` reads the feature property named `mag`, and `["linear"]`
selects linear interpolation.

<Code code={region(styleByData, "expression")} lang="c" title="style-by-data.c" />

Interpolate the circle radius from 4 pixels at magnitude 1 to 24 pixels at
magnitude 6.

<Code code={region(styleByData, "property")} lang="c" title="style-by-data.c" />

Setting a property takes one layer and one property name, and the name is the
one that the style specification defines for that layer's type.

<Code code={region(styleByData, "set")} lang="c" title="style-by-data.c" />

Set a filter to select which source features the layer draws. It uses the same
JSON representation as a style property.

<Code code={region(styleByData, "filter")} lang="c" title="style-by-data.c" />

The host owns the byte storage. MapLibre parses or copies a property value or
filter before the call returns.

Render the next map update to show the new appearance. The
[style reference](/maplibre-native-ffi/reference/c/style_8h.html) defines property
and filter commands.
