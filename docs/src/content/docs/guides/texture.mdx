This guide shows how to render a continuous map into textures for another
renderer to draw, such as a UI framework, a game engine, or a compositor. It
builds on the frame loop from
[Render to a window](/maplibre-native-ffi/guides/window/#render-frames).

## Attach a texture ring

The session renders into a ring of textures, so your renderer can draw one frame
while the session renders the next.

Usually, you let the session create the ring on your GPU device. If your
framework hands you textures to render into, attach those as a borrowed ring
instead.

<Aside type="note">
  The snippets below use Vulkan. For another backend, use that backend's calls
  to attach and replace the texture ring, and to get each frame's texture. The
  other steps are the same.
</Aside>

Pass your graphics context, such as your device and queue. On Vulkan, if your
renderer submits to the same queue, also pass a lock, and hold it around your
own submissions.

As with a window, use your graphics thread as the driver if the texture uses
your OpenGL context, and the library thread otherwise. See
[Service driver work](/maplibre-native-ffi/guides/window/#service-driver-work).

## Draw each frame

Run the window's frame loop, but without [](api:MLN_FRAME_DEMAND_PRESENT), since
your renderer shows the frames instead.

When a frame renders, acquire it with [](api:mln_render_session_acquire_frame)
and get its texture for your backend.

When your reads finish, release the frame with
[](api:mln_acquired_frame_release), so the session can render into that texture
again. To sync on the GPU, see [](api:mln_gpu_sync_kind). Keep at most one frame
acquired, or the next frame waits for a free texture, and release every acquired
frame before you close the session.

<Snippet page="texture" region="acquire" />

## Resize the textures

First, release every acquired frame. Then resize an owned ring with
[](api:mln_render_session_resize), as for a window. For a borrowed ring, create
textures at the new size and set them as the session's target, then destroy the
old textures.
