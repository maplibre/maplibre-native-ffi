A still-image job uses a session-owned texture target with a ring depth of one.
The host requests a frame, waits for its terminal result, and starts readback of
the completed texture.

## Request one image

Create the map and target with the required logical extent. Start attachment and
retain both the returned attaching session and operation. This snippet uses
private OpenGL through EGL, so the native core worker creates and owns its
context. The host keeps the EGL display initialized until detach completes.

Submit one frame demand with a token that identifies the job. A core-worker
target needs no host graphics service.

Drain frame results until the matching token reaches a terminal disposition. A
rendered disposition supplies the frame generation for readback. Handle target
not ready according to the target's readiness source. No update and size pending
wait for a newer map update or matching extent generation.

## Read the pixels

Start readback after the rendered result. Readback is an operation routed
through the selected driver. Taking the result transfers owned premultiplied
RGBA8 bytes and their width, height, row stride, and byte length.
