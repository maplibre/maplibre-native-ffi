A still image renders one frame into a session-owned texture and reads its
pixels back to the CPU. The texture lives on a graphics device that native code
creates, so the host needs no graphics code of its own.

## Request one image

Create a static map at the image size.

<Code code={region(stillImage, "create")} lang="c" title="still-image.c" />

Create a graphics device for the build's render backend. Metal, Vulkan, and EGL
builds can create one. Other builds attach an owned texture target on a context
that the host creates.

<Code code={region(stillImage, "device")} lang="c" title="still-image.c" />

Attach a texture target on the device at the image size, with a core-worker
driver. The session keeps its own reference to the device, so you can release
the device once the attach call returns.

<Code code={region(stillImage, "attach")} lang="c" title="still-image.c" />

After attachment completes, load the style and request a still image on the
map. The request renders its own frame on the session once the map has loaded
what the image shows.

<Code code={region(stillImage, "request")} lang="c" title="still-image.c" />

Start readback once the still-image completion arrives.

<Code code={region(stillImage, "start-readback")} lang="c" title="still-image.c" />

## Read the pixels

Copy the pixels that you keep.

<Code code={region(stillImage, "read")} lang="c" title="still-image.c" />
