A host that renders map images offscreen, such as a tile service or a thumbnail
job, creates the map in static mode and attaches an owned texture target. A
static map renders one image per request and reports the outcome as an event.
Unlike a live view, this path needs no window, no swap chain, and no display
refresh callback.

Create the map at the size that the render target uses. A session attached at a
different size sets the map size on the map's owner thread, and the map keeps
its previous size until the next pump. A still-image request made before the new
size reaches the map produces an update that renders nothing.

The render session allocates the texture for an owned texture target at the
extent that the descriptor names. Each render backend has its own descriptor
type and attach function, and this snippet uses OpenGL through EGL.

<Code code={region(stillImage, "attach")} lang="c" title="still-image.c" />

Call `mln_render_session_render_update` on every turn of the loop, because a
static map advances its loading through the render calls themselves. The runtime
reports `MLN_RUNTIME_EVENT_MAP_STILL_IMAGE_FINISHED` from the map's run loop,
and that event can arrive before or after the render call that produced the
pixels. The image is ready once the event has arrived and a render call has
reported a frame.

<Code code={region(stillImage, "await")} lang="c" title="still-image.c" />

`drain_still_image_events` polls the runtime and reports whether this map's
image finished or failed.

Once the image is ready, `mln_texture_read_premultiplied_rgba8` copies it into
host memory. The copy is premultiplied RGBA8 in physical pixels, laid out with
`info.stride` bytes per row.

<Code code={region(stillImage, "read")} lang="c" title="still-image.c" />

To sample the pixels on the GPU rather than copy them, acquire the last frame
with `mln_<backend>_owned_texture_acquire_frame` and release it once the host
has finished reading the texture.

A host whose destination texture already exists, such as a material in a 3D
scene or a frame from a compositor's pool, attaches a borrowed texture target
instead. That host copies the pixels with the graphics API that allocated the
texture, because `mln_texture_read_premultiplied_rgba8` returns
`MLN_STATUS_UNSUPPORTED` for a borrowed target.
