# Scope: the cache file, the ambient cache, and offline regions.
---

import Snippet from "../../../components/Snippet.astro";

The library caches resources, so maps load faster and keep working without a
network. The ambient cache holds what maps loaded recently, and offline regions
hold whole areas that you download on purpose.

## Set a cache file

To keep the cache between runs, set a cache file path in
[](api:mln_runtime_options) when you create the runtime. Without one, the cache
lives in memory, and offline regions are lost when the runtime is released.

<Snippet page="offline" region="cache-file" />

## Manage the ambient cache

To bound the ambient cache's disk use, set its maximum size with
[](api:mln_runtime_set_maximum_ambient_cache_size). Offline regions don't count
toward it.

To free its space, clear it with
[](api:mln_runtime_run_cache_database_operation). When your tiles change,
invalidate it instead. It keeps the data, but maps check each resource with the
server before they use it.

<Snippet page="offline" region="ambient" />

## Download a region

Define the region with [](api:mln_offline_tile_pyramid_region_definition): the
style URL, the bounds, the zoom range, and the pixel ratio. To follow a shape
instead of a box, use [](api:mln_offline_geometry_region_definition) with a
GeoJSON geometry. Keep the zoom range tight, since each zoom level has four
times the tiles of the one before.

You can store any bytes with the region as metadata, such as its name.

Create the region with [](api:mln_runtime_create_offline_region), then start its
download with [](api:mln_runtime_set_offline_region_download_state). Maps on the
runtime use the region's resources whenever they load the same style URL.

<Snippet page="offline" region="download" />

## Track download progress

To track a download, observe its region with
[](api:mln_runtime_set_offline_region_observed), and its progress arrives as
events in your [event handler](/maplibre-native-ffi/guides/events-and-logs/).

<Snippet page="offline" region="progress" />

## Manage regions

List the regions in the cache file with
[](api:mln_runtime_list_offline_regions). A download stops when the runtime is
released, so to resume one, set its download active again.

When the server's data changes, invalidate the region with
[](api:mln_runtime_invalidate_offline_region), and maps check each of its
resources with the server before they use it. To refresh the region for offline
use, set its download inactive if it's active, then set it active. The download
fetches what the current style lists and no map has checked since. Resources
that only an earlier version of the style listed stay in the region until you
delete it, and the region's status counts them once the download stops. If the
style or a TileJSON document is missing or invalid, the download reports a
response error and goes on from the stored copy.

Delete a region you no longer need with
[](api:mln_runtime_delete_offline_region).
