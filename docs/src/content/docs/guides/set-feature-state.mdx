Feature state is data that your host attaches to one feature at runtime, and
that style expressions read while the map draws. One styling rule then covers
selection, hover, or a live value, because each feature supplies its own input.
Feature state belongs to the [map](/maplibre-native-ffi/concepts/#map).

## Set state on a feature

feature ID.

The state is a JSON object.

<Code code={region(featureState, "value")} lang="c" title="feature-state.c" />

<Code code={region(featureState, "set")} lang="c" title="feature-state.c" />

An expression reads one key with `feature-state`. A circle layer that enlarges
the selected feature sets `circle-radius` to
`["case", ["boolean", ["feature-state", "selected"], false], 10, 5]`.

Remove a key when its value is no longer needed.
