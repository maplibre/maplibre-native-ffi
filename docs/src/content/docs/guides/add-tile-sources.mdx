Drawing a tile endpoint takes two style objects: a source that describes where
the tiles are and how to read them, and a layer that draws them. Both belong to
the loaded style. Add them after a style-loaded event and again after every
later style load, as
[Load a Style](/maplibre-native-ffi/guides/load-a-style/) describes.

How you describe the source depends on what the server publishes. A server with
a TileJSON document describes itself, and MapLibre reads it. For any other
server you name the tile URLs and the tile set's properties yourself.

## From a TileJSON document

Pass the document URL and null options when the server publishes a TileJSON
document. MapLibre fetches the document and reads the tile URLs, the zoom range,
the scheme, the bounds, and the attribution from it. Then add a layer that names
the source.

<Code code={region(tilejsonSnippet, "source")} lang="c" title="tile-source-tilejson.c" />

Options override a few of the document's fields: the zoom range and the vector
encoding on a vector source, the tile size on a raster or raster-DEM source, and
the DEM encoding on a raster-DEM source. Set the vector encoding to MapLibre Tiles for such a server,
because vector tiles decode as MVT by default. A tile set whose integer streams
use FastPFOR encodings also needs the FastPFOR option on the map options.

A vector tile carries several named layers. A layer that draws one of them sets
`source` to the source ID and `source-layer` to the name inside the tile.

## From URL templates

Describe the tile set yourself when the server publishes no TileJSON document.
Each tile URL contains the `{z}`, `{x}`, and `{y}` placeholders, and MapLibre
fills them for each tile. Several URLs that differ only in host name let MapLibre
distribute the requests among those hosts.

## Elevation tiles and hillshade

Raster-DEM tiles carry elevation in their color channels, in one of two
encodings: Mapbox Terrain-RGB, the default, and Terrarium. Match the encoding
that your server documents, because decoding with the other one produces wrong
elevations.
