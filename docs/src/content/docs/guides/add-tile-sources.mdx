Drawing a tile endpoint takes two style objects: a source that describes where
the tiles are and how to read them, and a layer that draws them. Both belong to
the loaded style. Add them after a style-loaded event and again after every
later style load, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

How you describe the source depends on what the server publishes. MapLibre reads
tile URLs and properties from a TileJSON document. For other servers, supply the
tile URLs and properties directly.

## From a TileJSON document

Set `url` in the source JSON when the server publishes a TileJSON document.
MapLibre reads the tile URLs, zoom range, scheme, bounds, and attribution. Then add a layer that names the source.

<Code code={region(tilejsonSnippet, "source")} lang="c" title="tile-source-tilejson.c" />

For vector sources, `minzoom`, `maxzoom`, and `encoding` in the source JSON
override the loaded TileJSON. Vector tiles decode as MVT by default; set
`encoding` to `"mlt"` for MapLibre Tiles. Set `tileSize` for raster and raster-DEM
sources when the server uses a tile size other than 512. MapLibre Tiles data with
FastPFOR integer streams also requires the FastPFOR map option.

A vector tile carries several named layers. A layer that draws one of them sets
`source` to the source ID and `source-layer` to the name inside the tile.

## From URL templates

Supply URL templates when the server has no TileJSON document. Each template
contains the `{z}`, `{x}`, and `{y}` placeholders. MapLibre fills them for each
tile. Several templates with different host names distribute requests among
those hosts.

Set bounds and zoom levels to match the server's coverage, and preserve its
attribution. Bounds list west, south, east, and north. The default XYZ scheme
numbers rows from the north; set `scheme` to `"tms"` when the server numbers them
from the south.
