A source query reports the loaded features in a source, including features that
no layer draws. To find features at a screen position, use
[Query a map](/maplibre-native-ffi/guides/query-a-map/).

Run the query on a session that has rendered a frame. Continue caller-driver
service until the query completes.

A query covers the tiles that the source loaded for the current camera. Its
result therefore changes as the camera moves and more tiles arrive. A source
loads tiles only while a layer uses it.

## Expand a cluster

Use the `supercluster` extension on a cluster feature from a GeoJSON source.
Its `leaves` field returns the features in that cluster.

`supercluster` matches numbers by exact native JSON type. Encode `limit` and
`offset` as nonnegative integer literals so MapLibre reads them as unsigned
values.

<Code code={region(clusterLeaves, "arguments")} lang="c" title="cluster-leaves.c" />

<Code code={region(clusterLeaves, "query")} lang="c" title="cluster-leaves.c" />

returns, or copy it for later use.

<Code code={region(clusterLeaves, "leaves")} lang="c" title="cluster-leaves.c" />

Pass the Feature bytes from a queried feature to the extension query.
`supercluster` also matches `cluster_id` by exact JSON type. Preserve its
nonnegative integer literal; rewriting every number as a double produces a
successful query with an empty result.

The [query reference](/maplibre-native-ffi/reference/c/query_8h.html) covers
source queries and extension results.
