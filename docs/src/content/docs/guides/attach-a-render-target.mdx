A render session draws one map into one target. Choose a native surface for a
window or view, an owned texture target for offscreen rendering, or a borrowed
texture target for compositing into host textures. Map state remains available
after the session detaches.

## Choose graphics execution

A core-worker driver runs graphics work on a native thread. A
caller-graphics-thread driver requires service on the host's graphics thread.
Metal and Vulkan support either driver. WebGPU requires the caller driver.

### OpenGL targets

Existing EGL, WGL, and WebGL contexts use the caller driver. A private EGL owned
texture target uses a core worker and supports CPU readback. A transferred
`OffscreenCanvas` also uses a core worker. The
[target reference](/maplibre-native-ffi/reference/c/render__target_8h.html)
states each context's ownership rules.

### Shared Vulkan queues

Pass a queue lock when the host and session submit to the same Vulkan queue.
Both take the same lock around queue calls. Release it before calling the C API
so that driver work can acquire it.

## Attach the target

Provide the graphics context and extent in the backend descriptor. Install wakes
to schedule frame-result drains and caller-driver service. Wake callbacks must
return without blocking. Keep the host's graphics resources alive until teardown
finishes.

Attachment returns a session and completes asynchronously. Service a caller
driver while attachment is pending, and await completion before using the
attached session.

the target. Keep the outgoing textures until replacement completes. Replace a

<Code code={region(renderTarget, "set-target")} lang="c" title="render-target.c" />

A target replacement can change the session's scale factor; the map retains its
creation scale factor. Keep them equal for a consistent display density.

For normal shutdown, release acquired frames with their consumer synchronization,
detach the session, and continue caller-driver service until detach completes.
Then destroy the session and the host graphics resources.

Abandon handles a target whose graphics work can no longer be serviced. Stop
caller-driver service first. Abandon may keep graphics resources until process
exit; inspect its result before destroying the host resources that they depend
on. The [session reference](/maplibre-native-ffi/reference/c/render__session_8h.html)
defines those retention rules.
