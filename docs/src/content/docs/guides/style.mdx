A style describes what a map shows: its sources supply data, and its layers draw
that data in order. This guide shows how to load a style and change its sources,
layers, and images. Sources and layers use the JSON of the
[MapLibre style spec](https://maplibre.org/maplibre-style-spec/).

## Load a style

Set the style by URL with [](api:mln_map_set_style_url), or by JSON with
[](api:mln_map_set_style_json). Either one completes once the map has parsed the
style, or fails when the style doesn't load.

<Aside type="caution">
  Loading a style replaces the sources, layers, and images you added. Wait for
  the load to complete before you add or change them, because until it does,
  those changes fail. A new map has no style, so load one first, even an empty
  one.
</Aside>

## Add a source and a layer

Add a source by its ID and its JSON with [](api:mln_map_add_style_source_json).
The JSON is the same object that a style puts under `sources`. See
[Sources](https://maplibre.org/maplibre-style-spec/sources/) in the style spec.

Add a layer by its JSON with [](api:mln_map_add_style_layer_json). It draws on
top, unless you give the ID of a layer to draw it under. See
[Layers](https://maplibre.org/maplibre-style-spec/layers/) in the style spec.

<Snippet page="style" region="add" />

For GeoJSON data in memory, prepare it as [](api:mln_geo_json_source_data)
first, then add a GeoJSON source with [](api:mln_map_add_geo_json_source_data).
Preparing processes the data before it reaches the map, so you can do it on any
thread, off your event loop. A source whose JSON holds its GeoJSON data inline
works too, but the map processes that data on its own thread. To update the
source, set new prepared data with [](api:mln_map_set_geo_json_source_data).

<Snippet page="style" region="geojson" />

To remove a source, first remove the layers that use it with
[](api:mln_map_remove_style_layer), then the source with
[](api:mln_map_remove_style_source).

## Change a layer

Set a layer property by its style-spec name and a JSON value with
[](api:mln_map_set_style_layer_property). This also covers `visibility` and
`filter`. A value can be an
[expression](https://maplibre.org/maplibre-style-spec/expressions/).

Each change can show up in its own frame. To show several changes together, send
them between [](api:mln_map_begin_command_group) and
[](api:mln_map_end_command_group).

<Snippet page="style" region="set-property" />

## Add an image

Add an image to the style by its ID and premultiplied RGBA pixels with
[](api:mln_map_set_style_image). Symbol layers then draw it by that ID in
`icon-image`.

<Snippet page="style" region="image" />

When a layer asks for an image the style doesn't have, the map sends a
missing-image event, whose [](api:mln_runtime_event_style_image.image_id) names
the image. Set the image when the event arrives.
