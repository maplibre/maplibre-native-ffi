A rendered feature query finds the features drawn at a screen position, for hit
testing. To read source features that no layer draws, use
[Query a source](/maplibre-native-ffi/guides/query-a-source/).

The query reads the last frame that the session drew, so run it after a frame
renders.

Search a box of a few logical pixels around the position rather than a point,
because symbols and thin lines are small targets.

Each hit carries its feature as GeoJSON and the ID of the style layer that drew
it. A feature that several layers draw, such as a fill and its outline, yields
one hit per layer. Copy what you keep.
