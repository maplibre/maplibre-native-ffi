Data appears on the map through two style objects. A source contains the
GeoJSON, and a layer draws its features. Add both after a style-loaded event.
Repeat the additions after every later style load, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

## Choose the data form and the options

A source reads its data from a URL or from host memory. Use
`mln_map_add_geo_json_source_url` for data that a server publishes, and
`mln_map_add_geo_json_source_data` for data that the host computes or receives
itself.

Choose source options, such as clustering, when you add the source. Changing
them later means replacing the source and its layers.

The layer is a style-spec layer object with at least an `id`, a `type`, and the
`source` ID. Choose the type that matches your geometry: a circle layer draws
points, a line layer draws line strings, and a fill layer draws polygons.

## Supply the data from memory

Inline data is a complete GeoJSON value from the host's serializer, which the
host prepares and then installs. Prepare a large dataset on a host worker
thread. Clustering requires a FeatureCollection of point features.
