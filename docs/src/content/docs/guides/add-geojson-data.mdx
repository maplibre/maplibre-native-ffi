Your data appears on the map through two objects. A source holds the GeoJSON,
and a layer draws the features that the source contains. Both belong to the
style that is loaded when you add them, so add them after a style-loaded event
and again after every later style load, as
[Load a Style](/maplibre-native-ffi/guides/load-a-style/) describes.

## Choose the data form and the options

A source reads its data in one of two forms.
`mln_map_add_geojson_source_url` names a URL, which MapLibre fetches through its
resource system and reloads on its own. It suits data that a server publishes.
`mln_map_add_geojson_source_data` takes geometry and feature descriptors that
your host already holds in memory, and copies them before it returns. It suits
data that your host computes or receives over its own transport.

The source options are the other choice, and they are fixed for the source's
lifetime. Clustering carries the highest cost of changing your mind: switching
it later requires removing the source and every layer that draws it, then adding
them again. A clustering source groups nearby points into cluster features, and
the cluster radius, the highest zoom that clusters, and the number of points
that a cluster requires belong to the same options.

The layer is a style-spec layer object with at least an `id`, a `type`, and the
`source` ID. Choose the type that matches your geometry: a circle layer draws
points, a line layer draws line strings, and a fill layer draws polygons.

appends the layer above the rest of the style, and naming an existing layer

## Supply the data from memory

Inline data replaces the URL with a GeoJSON descriptor that you build. A
clustering source constrains that descriptor, and the call returns
an invalid-argument status unless the data is a feature collection whose
every feature carries point geometry.

<Code code={region(geojsonDataset, "inline-data")} lang="c" title="geojson-dataset.c" />

MapLibre tiles the data on its own threads either way. A host that already pumps
the runtime and renders on update draws the new features in the first frame
after that work finishes.
