Data appears on the map through two style objects. A source contains the
GeoJSON, and a layer draws its features. Add both after a style-loaded event.
Repeat the additions after every later style load, as
[Load a style](/maplibre-native-ffi/guides/load-a-style/) describes.

## Choose the data form and the options

A source reads its data from a URL or from host memory. Use
`mln_map_add_geojson_source_url` for data that a server publishes. MapLibre
fetches the URL through its resource system and reloads it when requested. Use
`mln_map_add_geojson_source_data` for data that the host computes or receives
through its own transport. Prepare inline data by parsing and tiling the
GeoJSON, then install the prepared result.

Choose source options at creation and keep them when preparing later data.
Clustering groups nearby points; its options control the radius and zoom range.
Changing source options requires replacing the source and its layers.

## Supply the data from memory

Inline data uses a complete GeoJSON value produced by the host's serializer.
Prepare large datasets on a host worker thread. Install the prepared handle,
then destroy it when the host has finished using it. Clustering requires a
FeatureCollection containing point features.

<Code code={region(geojsonDataset, "inline-data")} lang="c" title="geojson-dataset.c" />

A URL source parses and tiles on worker threads after the fetch. A host that
renders on update draws the new features after tiling finishes. [Update
data](/maplibre-native-ffi/guides/update-data/) covers replacing inline data as
it changes.

The [style reference](/maplibre-native-ffi/reference/c/style_8h.html) defines
GeoJSON preparation and source options.
