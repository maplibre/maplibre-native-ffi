MapLibre Native FFI is the
[MapLibre Native](https://github.com/maplibre/maplibre-native) map engine as a C
API, with bindings for Dart, Go, Kotlin, .NET, Python, Rust, Swift, TypeScript,
and Zig. Use it to build map components for a UI framework, or to render maps on
a server.

To start, [install](/maplibre-native-ffi/install/) the package for your
language, then [create a map](/maplibre-native-ffi/guides/create-a-map/).

To see it run, open the [live demo](/maplibre-native-ffi/demo/), which renders a
map in your browser with the TypeScript binding, on WebGL or WebGPU.

## Used by

- [MapLibre Compose](https://github.com/maplibre/maplibre-compose) brings maps
  to Compose Multiplatform.
- [MapLibre for Flutter](https://github.com/josxha/flutter-maplibre) brings maps
  to Flutter.
- [Rampardos](https://github.com/lenisko/rampardos) renders static maps and
  raster tiles from local MBTiles.
- [Mapigrade](https://github.com/greensopinion/mapigrade) draws a MapLibre
  Native map into a Flutter `Texture` widget as the base layer of a
  [`flutter_map`](https://pub.dev/packages/flutter_map) map.
