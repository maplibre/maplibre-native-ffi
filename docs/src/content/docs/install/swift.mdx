## Install

Add the package from its
[distribution repository](https://github.com/maplibre/maplibre-native-ffi-distribution),
which tags each release with its version. It needs Swift 6.2 or later.

```swift title="Package.swift"
.package(
  url: "https://github.com/maplibre/maplibre-native-ffi-distribution",
  exact: "{{version}}"
)
```

Then depend on its `MaplibreNativeFFI` product:

```swift title="Package.swift"
.product(name: "MaplibreNativeFFI", package: "maplibre-native-ffi-distribution")
```

The package takes the C library from the release: on Apple platforms, its
[XCFramework](/maplibre-native-ffi/install/c/#swift-package-manager), and
elsewhere an artifact bundle that links it statically. SwiftPM downloads the
XCFramework and both bundles, about 350 MB, whichever platform you build for.

## Choose a backend

On Apple platforms, the package renders with Metal. Elsewhere it uses your
platform's [default backend](/maplibre-native-ffi/install/#choose-a-backend). To
choose another, enable one trait, `OpenGL` or `Vulkan`, in place of the default:

```swift title="Package.swift"
.package(
  url: "https://github.com/maplibre/maplibre-native-ffi-distribution",
  exact: "{{version}}",
  traits: ["Vulkan"]
)
```

## Android

Initialize the library once per process, before you create a runtime, with the
calling thread's JNI environment and an Android `Context`:

```swift title="main.swift"
try initAndroid(
  jniEnv: NativePointer(bitPattern: jniEnv),
  context: NativePointer(bitPattern: context))
```

## Snapshots

Depend on this repository at `main`. SwiftPM names the package after the
repository:

```swift title="Package.swift"
.package(url: "https://github.com/maplibre/maplibre-native-ffi", branch: "main")
```

```swift title="Package.swift"
.product(name: "MaplibreNativeFFI", package: "maplibre-native-ffi")
```

This package finds the C library with pkg-config, on Apple platforms too.
Download and unpack the C library for your preset from the
[snapshot release](https://github.com/maplibre/maplibre-native-ffi/releases/tag/unstable-native-snapshot),
and point pkg-config at it before you build:

```bash frame="terminal"
export PKG_CONFIG_PATH=<prefix>/share/pkgconfig
```

SwiftPM ignores the rpath that pkg-config adds, so on Linux, pass the prefix's
`lib` directory to the linker:

```bash frame="terminal"
swift build -Xlinker -rpath -Xlinker <prefix>/lib
```

On Windows, put the prefix's `bin` directory on `PATH`, or copy the DLLs in it
next to the executable.
