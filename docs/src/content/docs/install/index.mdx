## Choose a backend

The library renders with one graphics backend, which you choose when you install
it. Apple platforms have one, Metal. Elsewhere, where a package has a default,
it's OpenGL on Android and OpenHarmony, WebGPU in browsers, and Vulkan on other
platforms. Choose OpenGL in emulators and virtual machines, which often lack
Vulkan, and choose the backend your application already uses if it draws its own
graphics.

## Web

In a browser, the library is a WebAssembly module for one backend, WebGPU or
WebGL 2, that runs on the thread that loads it and never blocks it. Completions,
events, and callbacks arrive in tasks of their own after the call that started
them returns, so await them. Load the library on a dedicated
[Web Worker](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API),
so that the map's work doesn't delay the page, and draw to an `OffscreenCanvas`
that the page transfers to it with
[`transferControlToOffscreen()`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/transferControlToOffscreen).
On the page's thread it works too, but every frame and style parse runs there.

The module starts Web Workers of its own for tile work, and needs no
cross-origin isolation, so any static host serves it.
