## Install

The TypeScript binding runs on Node.js, Bun, Deno, in browsers, in React Native
and other Hermes hosts, and on OpenHarmony. Each runtime takes a runtime
package, which holds the native library with every
[backend](/maplibre-native-ffi/install/#choose-a-backend) of your platform, or
in a browser, the module of one backend. Install from npm, or from OHPM on
OpenHarmony, as the section for your runtime shows.

## Node.js, Bun, and Deno

Add the binding and its runtime package from
[npm](https://www.npmjs.com/package/@maplibre/native-ffi). It needs Node.js
24.11, Bun 1.4.3, Deno 2.9.7, or later.

```bash frame="terminal"
npm install @maplibre/native-ffi @maplibre/native-ffi-runtime
```

Deno imports the binding as `npm:@maplibre/native-ffi`, and needs
`--allow-ffi --allow-read --allow-env`.

The runtime package uses MSVC on Windows. For MinGW on x64, install
`@maplibre/native-ffi-runtime-mingw` instead.

## Browser

Add the binding and `@maplibre/native-ffi-runtime-webgpu`, which renders with
WebGPU, or `@maplibre/native-ffi-runtime-webgl`, which renders with WebGL 2.
Serve the files of the runtime package as static files, together, such as from
Vite's `public` directory: the module loads its tile workers' script and its
font shaper by URLs relative to its own. Load it before any other call, on a Web
Worker:

```ts title="map-worker.ts"
import { loadModule, RuntimeHandle, WebObject } from "@maplibre/native-ffi";

await loadModule(new URL("/maplibre_native_ffi.js", location.href));
const runtime = RuntimeHandle.create();
```

Lend the module JavaScript objects, such as the `OffscreenCanvas` that a web
canvas target takes, with `WebObject.of(canvas)`, and pass its `handle`.

The page must meet the [web requirements](/maplibre-native-ffi/install/#web).

## React Native

Add `@maplibre/native-ffi-react-native` from npm. It needs React Native's new
architecture, and carries the native library: Vulkan and OpenGL ES on Android,
and Metal on iOS.

```bash frame="terminal"
npm install @maplibre/native-ffi-react-native
```

Import the binding from this package, which installs it in the app's runtime
first:

```tsx title="Map.tsx"
import {
  MaplibreSurfaceView,
  RuntimeHandle,
  surfaces,
} from "@maplibre/native-ffi-react-native";
```

`MaplibreSurfaceView` reports its native surface, which `surfaces.acquire()`
turns into the handles to attach a render session with. The package's README
covers the surface lifecycle.

## Other Hermes hosts

To embed the binding in a Hermes runtime, install the package and import its
Hermes entry:

```ts title="index.ts"
import { RuntimeHandle } from "@maplibre/native-ffi/hermes";
```

Your native host links the C library and the package's `native/hermes` CMake
target against its Hermes JSI library. It installs `mln::hermes::Module` before
it loads JavaScript, and supplies a scheduler for the runtime thread. The
package's `module.h` states the threading and lifetime rules. On Android, the
host also calls `mln_android_init` before it creates a runtime.

## OpenHarmony

Add the binding and its runtime package, which carries Vulkan and OpenGL ES,
from [OHPM](https://ohpm.openharmony.cn/#/en/detail/@maplibre%2Fnative-ffi):

```bash frame="terminal"
ohpm install @maplibre/native-ffi @maplibre/native-ffi-runtime
```

Keep both packages on the same version.

```ts title="Index.ets"
import { RuntimeHandle } from "@maplibre/native-ffi";

const runtime = RuntimeHandle.create();
```

## Use your own build

npm has no snapshots. To try `main`, pack the packages for your preset in a
checkout of this repository, then install the tarballs:

```bash frame="terminal"
mise run //bindings/typescript:pack linux-gnu-x64
npm install path/to/maplibre-native-ffi/bindings/typescript/build/npm/*.tgz
```

For OpenHarmony, pack and install both HARs instead:

```bash frame="terminal"
mise -E ohos run //bindings/typescript:pack-ohpm ohos-arm64
ohpm install path/to/maplibre-native-ffi/bindings/typescript/build/ohpm/*.har
```
