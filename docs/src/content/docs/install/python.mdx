## Install

Install the binding and its runtime from
[PyPI](https://pypi.org/project/maplibre-native-ffi/). It needs Python 3.12 or
later. The runtime holds the native library, with every
[backend](/maplibre-native-ffi/install/#choose-a-backend) of your platform.
Importing the binding fails unless exactly one runtime is installed.

```bash frame="terminal"
pip install maplibre-native-ffi maplibre-native-ffi-runtime
```

## Windows with MinGW

The runtime above uses MSVC on Windows. For MinGW, install
`maplibre-native-ffi-runtime-mingw` instead.

## Android

Initialize the library once per process, before you create a runtime, with the
calling thread's JNI environment and an Android `Context`:

```python title="main.py"
maplibre_native_ffi.api.init_android(jni_env, context)
```
