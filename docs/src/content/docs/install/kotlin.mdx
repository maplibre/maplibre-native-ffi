## Install

Add the binding to your common source set from Maven Central:

```kotlin title="build.gradle.kts"
repositories {
  mavenCentral()
}

kotlin {
  sourceSets {
    commonMain.dependencies {
      implementation("org.maplibre.nativeffi:maplibre-native-ffi:{{version}}")
    }
  }
}
```

Then add a runtime to each target, as the sections below show.
`maplibre-native-ffi-runtime` holds the native library of every native platform,
with every [backend](/maplibre-native-ffi/install/#choose-a-backend) of each. In
a browser, `maplibre-native-ffi-runtime-webgpu` and
`maplibre-native-ffi-runtime-webgl` each hold one backend.

## Android

Android needs API level 24 or later. Add a runtime to `androidMain`:

```kotlin title="build.gradle.kts"
androidMain.dependencies {
  implementation("org.maplibre.nativeffi:maplibre-native-ffi-runtime:{{version}}")
}
```

Call `initAndroid(context)` once before you create a runtime.

## Native

Add the runtime to the source set of each native target, such as Apple platforms
and Linux:

```kotlin title="build.gradle.kts"
appleMain.dependencies {
  implementation("org.maplibre.nativeffi:maplibre-native-ffi-runtime:{{version}}")
}
linuxMain.dependencies {
  implementation("org.maplibre.nativeffi:maplibre-native-ffi-runtime:{{version}}")
}
```

## JVM

The JVM needs JDK 25 or later. Its runtime holds the native library in a
separate JAR for each platform. Add the JAR for each platform that your
application runs on, by its classifier: `natives-<os>-<arch>`, such as
`natives-linux-x64` or `natives-macos-arm64`. Use `linux-musl` for musl, and
`windows-mingw` for MinGW on Windows.

```kotlin title="build.gradle.kts"
jvmMain.dependencies {
  runtimeOnly("org.maplibre.nativeffi:maplibre-native-ffi-runtime-jvm:{{version}}:natives-linux-x64")
}
```

The binding calls native code through Java's foreign function API, so start the
JVM with `--enable-native-access=ALL-UNNAMED`.

## Wasm

Add `maplibre-native-ffi-runtime-webgpu` to `wasmJsMain` to render with WebGPU,
or `maplibre-native-ffi-runtime-webgl` to render with WebGL 2. Before you use
the binding, call `loadWasmModule()` and wait for it, on the thread that runs
your Kotlin: a Web Worker, as the
[web requirements](/maplibre-native-ffi/install/#web) suggest, or the page. Lend
the module your canvas and other JavaScript objects as `WebObject`s, whose
handles the descriptors take.

## Snapshots

Snapshots of `main` publish daily to the Maven snapshot repository, as version
`0.1.0-SNAPSHOT`:

```kotlin title="build.gradle.kts"
repositories {
  maven("https://central.sonatype.com/repository/maven-snapshots/") {
    content { includeGroup("org.maplibre.nativeffi") }
  }
  mavenCentral()
}
```

Then use `0.1.0-SNAPSHOT` as the version of the binding and its runtimes.
