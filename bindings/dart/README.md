# MapLibre Native FFI for Dart

`maplibre_native_ffi` is the low-level Dart binding for the C API of
[MapLibre Native FFI](https://maplibre.org/maplibre-native-ffi/), which embeds
the [MapLibre Native](https://github.com/maplibre/maplibre-native) map renderer.

- [Install](https://maplibre.org/maplibre-native-ffi/install/#dart)
- [Guides](https://maplibre.org/maplibre-native-ffi/guides/create-a-map/)
- [API reference](https://maplibre.org/maplibre-native-ffi/reference/dart/)
