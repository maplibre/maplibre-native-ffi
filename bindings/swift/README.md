# MapLibre Native FFI for Swift

`MaplibreNativeFFI` is the low-level Swift binding for the C API of
[MapLibre Native FFI](https://maplibre.org/maplibre-native-ffi/), which embeds
the [MapLibre Native](https://github.com/maplibre/maplibre-native) map renderer.

- [Install](https://maplibre.org/maplibre-native-ffi/install/#swift)
- [Guides](https://maplibre.org/maplibre-native-ffi/guides/create-a-map/)
- [API reference](https://maplibre.org/maplibre-native-ffi/reference/swift/documentation/maplibrenativeffi/)
