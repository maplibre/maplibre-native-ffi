# MapLibre Native FFI for Kotlin

`org.maplibre.nativeffi:maplibre-native-ffi` is the low-level Kotlin binding for
the C API of [MapLibre Native FFI](https://maplibre.org/maplibre-native-ffi/),
which embeds the [MapLibre Native](https://github.com/maplibre/maplibre-native)
map renderer.

- [API reference](https://maplibre.org/maplibre-native-ffi/reference/kotlin/)
