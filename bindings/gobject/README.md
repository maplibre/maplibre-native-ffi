# MapLibre Native FFI for GObject

`maplibre-native-ffi-gobject` is the low-level GObject library over the C API of
[MapLibre Native FFI](https://maplibre.org/maplibre-native-ffi/), which embeds
the [MapLibre Native](https://github.com/maplibre/maplibre-native) map renderer.
C programs use its header and pkg-config file, GJS and PyGObject its typelib,
Vala its VAPI, and other GObject language bindings its GIR.
