# MapLibre Native FFI for Rust

`maplibre-native-ffi` is the low-level Rust binding for the C API of
[MapLibre Native FFI](https://maplibre.org/maplibre-native-ffi/), which embeds
the [MapLibre Native](https://github.com/maplibre/maplibre-native) map renderer.

- [Install](https://maplibre.org/maplibre-native-ffi/install/#rust)
- [Guides](https://maplibre.org/maplibre-native-ffi/guides/create-a-map/)
- [API reference](https://maplibre.org/maplibre-native-ffi/reference/rust/maplibre_native_ffi/)
