# MapLibre Native FFI for TypeScript

`@maplibre/native-ffi` is the low-level TypeScript binding for the C API of
[MapLibre Native FFI](https://maplibre.org/maplibre-native-ffi/), which embeds
the [MapLibre Native](https://github.com/maplibre/maplibre-native) map renderer.

- [Install](https://maplibre.org/maplibre-native-ffi/install/#typescript)
- [Guides](https://maplibre.org/maplibre-native-ffi/guides/create-a-map/)
- [API reference](https://maplibre.org/maplibre-native-ffi/reference/typescript/)
