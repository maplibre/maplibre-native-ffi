# Contributing

Issues track actionable work, such as bugs and concrete feature requests. Ask
questions in
[Q&A](https://github.com/maplibre/maplibre-native-ffi/discussions/categories/q-a)
and discuss open-ended ideas in
[Ideas](https://github.com/maplibre/maplibre-native-ffi/discussions/categories/ideas).
Maintainers file issues for the work that comes out of a discussion.

If you use AI assistance, follow the [AI policy](./AI_POLICY.md).

To set up a checkout, follow the
[development overview](https://maplibre.org/maplibre-native-ffi/development/overview/).
Before you change the public API, read the
[guidelines](https://maplibre.org/maplibre-native-ffi/development/guidelines/).

Pull request titles follow
[Conventional Commits](https://www.conventionalcommits.org/).
