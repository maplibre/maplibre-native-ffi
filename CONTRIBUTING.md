# Contributing

Discuss changes in `#maplibre` on the
[OSM-US Slack](https://slack.openstreetmap.us/).

[`AGENTS.md`](./AGENTS.md) maps the repository and lists its commands and rules.
The
[development overview](https://maplibre.org/maplibre-native-ffi/development/overview/)
covers machine setup, cross-compilation, and CI. Read
[Concepts](https://maplibre.org/maplibre-native-ffi/concepts/) before you change
behavior, and [`tools/bindgen/README.md`](./tools/bindgen/README.md) before you
change a C declaration or a binding.

Keep each pull request to one reviewable change. Fill in the PR template, and
follow the [AI policy](./AI_POLICY.md) if you use AI assistance.
