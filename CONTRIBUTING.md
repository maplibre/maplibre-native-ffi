# Contributing

Discuss changes in `#maplibre` on the
[OSM-US Slack](https://slack.openstreetmap.us/).

[`AGENTS.md`](./AGENTS.md) states the project's priorities and rules. The
[development overview](https://maplibre.org/maplibre-native-ffi/development/overview/)
covers machine setup, cross-compilation, and CI. Read
[Concepts](https://maplibre.org/maplibre-native-ffi/concepts/) before you change
behavior, and the
[C API guidelines](https://maplibre.org/maplibre-native-ffi/development/c-api-guidelines/)
before you change a C declaration or a binding.

Keep each pull request to one reviewable change, and follow the
[AI policy](./AI_POLICY.md) if you use AI assistance.
